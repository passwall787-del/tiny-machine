# Tiny Machine 路线图

## P0 · 物理核心验证 — 完成
- 小球、木板、斜坡、目标区
- 基础重力与碰撞
- Android 触摸拖动
- 开始 / 暂停 / 重置
- 第一关可解性与 UI 对比度修复

## P1 · 机关系统 — 核心完成，进入长期迭代
- Spring / Switch / Gear
- Rope / Scissors / Balloon
- Magnet / Bomb
- 目标进入立即终止模拟并进入 SUCCESS
- 机关测试与基础回归

## P2 · 关卡编辑器 — 完成首版
- 删除、旋转、多选
- 撤销、重做
- 20px 网格吸附
- LevelData + JSON 数据格式
- 关卡验证器
- 本机保存 / 加载
- ComponentFactory / LevelRuntime / MachineComponent 分层

## P3 · 内容与体验 — 首轮完成，当前做 P3.1
- 32 个官方关卡
- 5 个教程阶段
- 1~8 星难度曲线
- 成功 / 失败反馈动画
- 程序化音效与轻量 BGM
- P2 编辑器能力继续保留
- Android ARM64 CI + 自动化数据测试

### P3.1 · 施工流程与视觉重构 — 当前
- 官方关卡施工区从空白开始。
- 小球作为固定 START 发射源，不占零件库存。
- 有限 Parts Bin / 零件仓库。
- 玩家点击取件、拖动、旋转、组合后再发射小球。
- 重新设计移动端施工台布局。
- 提升所有核心组件的程序化视觉表现。
- 真机逐关重新验证新的搭建难度曲线。
