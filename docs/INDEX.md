# 文档索引

- `PROJECT_STATUS.md`：当前状态、技术债、交接入口
- `ROADMAP.md`：P0~P5 路线
- `ARCHITECTURE.md`：运行时与数据架构
- `GAMEPLAY.md`：核心规则与状态机
- `COMPONENTS.md`：组件行为和物理层
- `LEVEL_DESIGN.md`：关卡结构、难度与可解性
- `BUILD_ANDROID.md`：Android CI / APK 构建
- `TEST_PLAN.md`：自动化与真机回归
- `LEVEL_001.md` / `LEVEL_002.md`：早期 P0/P1 关卡记录，当前以 `levels.json` 为主数据源
- `ADR.md`：关键架构决策
- `DEBUGGING.md`：调试方法
- `DEVELOPMENT.md`：开发规范
- `PRODUCT.md`：产品范围
- `RELEASE_CHECKLIST.md`：发布检查

## 文档维护规则
代码、关卡、状态机、Android 构建或验收状态变化时，必须同步更新相关文档；自动化测试结果和 APK SHA-256 必须记录到构建/验收文档。
