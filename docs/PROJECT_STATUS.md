# 项目当前状态 / Handoff

## 当前阶段

**P3.1：视觉与施工流程重构。**

P3 的第一轮内容与自动化回归已经完成；本轮根据试玩方向，把游戏从“预摆零件的功能 Demo”调整为真正的“空施工区 → 零件仓库 → 玩家搭建 → 发射小球”流程，同时开始替换简陋的视觉占位。

## 本轮已完成

- 官方关卡进入时施工区为空。
- 小球作为固定 START 发射源，不属于玩家零件。
- 零件仓库显示每种组件的剩余数量。
- 点击零件卡片即可添加组件。
- 添加后自动选中，方便立即拖动调整。
- 零件用完后仓库卡片禁用。
- 没有放置零件时“发射小球”按钮禁用。
- 重新施工会清空本关布局，而不是恢复预置机器。
- 增加更完整的移动端施工台视觉层级。
- 增加组件卡片图标、数量徽标和状态视觉。
- 重做 Board / Slope / Spring / Rope / Scissors / Gear / Switch / Balloon / Magnet / Bomb / Ball 的轻量矢量视觉。
- 小球从 `runtime.components` 中独立出来，避免被玩家误删或占用库存。
- 自动化 playability runner 改为：加载空关卡 → 注入隐藏的测试解法 → 发射 → 验证 SUCCESS；玩家运行时不会看到测试解法。

## P3 自动化门禁

- 核心 `.gd` 可加载且可实例化。
- 32 个官方关卡结构验证。
- 官方关卡必须以空施工区开始。
- 每关必须存在自动化解法布局和有限库存。
- 主场景 runtime smoke：验证空场地 → 添加零件 → 发射 → SUCCESS。
- 32 个官方解法逐关物理运行到 SUCCESS。
- Android ARM64 APK 导出并完成 APK 签名校验。

## P2 能力

删除、旋转、多选、撤销、重做、网格吸附、保存/加载、本机关卡验证均保留。

## P3 内容

- 官方关卡：32
- 教程：1~5
- 难度：1~8 星
- Magnet / Bomb
- SUCCESS：目标进入立即停止模拟
- FAIL：掉出施工区或超过 18 秒
- 成功/失败动画
- 程序化音效 / BGM
- Android ARM64 debug APK

## 当前技术债

1. Rope 仍是逻辑剪断原型。
2. Gear 仍是简化机械传递。
3. 组件视觉目前为程序化矢量版本，后续还可以继续提升为正式 2D 美术资源。
4. 32 关自动化可解性已验证，但需要重新进行 Android 真机逐关体验，确认“空场搭建”的难度曲线是否合理。
5. UI 和部分玩法编排仍集中在 `main.gd`。
6. Android 当前为 debug APK；正式发布需要签名 AAB。
