# UI / UX 规范

## 1. 目标

手机上优先保证：

- 看得见。
- 点得到。
- 拖得准。
- 运行状态清晰。

## 2. P1 顶部工具栏

当前采用两行结构：

```text
TINY MACHINE · P1
编辑说明 / 目标终止规则

[关卡] [小球] [木板] [斜坡] [弹簧] [绳子] [剪刀] [齿轮] [开关] [气球] [开始] [重置]
```

## 3. 按钮对比度

上一版存在按钮与背景颜色过于接近的问题。

P1 固定：

- 主操作：高亮蓝色。
- 普通操作：独立深色面板 + 明显边框。
- 文字：高对比度浅色。
- Disabled：明显降低亮度，但仍可识别。
- Pressed：边框加粗。

## 4. 编辑 / 运行

编辑状态：

- 组件可拖动。
- 组件有选中高亮。
- 关卡可切换。
- 可以添加组件。

运行状态：

- 组件不能拖动。
- 组件拥有物理状态。
- Start 变为 Pause。

成功状态：

- Start 变为 `✓ 完成`。
- 组件停止。
- 所有编辑控件禁用。
- Reset 保留可用。

## 5. 触摸

所有可编辑组件必须具备足够大的 CollisionShape2D 作为点击/拖动区域。Godot 的 CollisionObject2D 输入事件要求对象可拾取且至少有一个 collision layer。 

## 6. 目标反馈

目标区持续显示：

- 绿色圆环。
- 内部高亮。
- TARGET 标签。

成功后目标区进入更亮的成功状态。

## 7. 机关反馈

P1 机关必须能够看出状态：

- Switch：OFF / ON。
- Spring：待机 / 激活。
- Gear：静止 / 旋转。
- Rope：完整 / 剪断。
- Scissors：待机 / 已触发。
- Balloon：可见上浮方向。

## 8. 手机可读性

避免：

- 过小字体。
- 低对比度文字。
- 过细边框。
- 需要精确点击 1~2 px 的按钮。
