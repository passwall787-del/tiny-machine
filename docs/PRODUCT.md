# 产品与范围

## 产品定位
Tiny Machine 是移动端 2D 物理机关解谜游戏。玩家通过摆放机械组件设计因果链，然后观察系统自动运行。

核心乐趣：
- 空间规划
- 因果推理
- 物理直觉
- 试错与调整
- 连锁反应

## 核心循环

```text
目标 → 观察组件 → 摆放/旋转 → 运行 → 观察结果 → 调整 → 成功
```

## P0~P3

### P0
基础物理、触摸、目标和运行循环。

### P1
Spring / Switch / Gear / Rope / Scissors / Balloon / Magnet / Bomb，以及终端通关状态。

### P2
数据驱动关卡与编辑器：删除、旋转、多选、撤销、重做、网格吸附、保存/加载、验证。

### P3
32 个首轮官方关卡、教程、难度曲线、成功/失败反馈、程序化音效和 BGM。

## P4/P5
P4 再做在线关卡、账号、分享和排行榜；P5 再做正式签名、商店和商业化。

## 产品原则
1. 物理规则要可理解。
2. 机关触发要有明显反馈。
3. 编辑操作必须低门槛。
4. 困难来自因果链，而不是随机性。
5. 关卡先自动验证，再 Android 真机验证。
6. 不复制原游戏代码、素材或受版权保护关卡。
