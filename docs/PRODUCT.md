# 产品与范围

## 1. 产品定位

Tiny Machine 是一款移动端 2D 物理机关解谜游戏。核心乐趣来自玩家设计一条“因果链”，然后观察系统按照物理规则自动运行。

产品不追求纯反应速度，而追求：

- 空间规划
- 因果推理
- 物理直觉
- 试错和调参
- 复杂连锁反应

## 2. 核心体验

玩家应该经历以下心理过程：

```text
“我需要把 A 送到 B。”
        ↓
“我手里有哪些组件？”
        ↓
“如果先让球撞这里，会发生什么？”
        ↓
“这个机关的时机对吗？”
        ↓
“开始运行。”
        ↓
“差一点，再调整一次。”
        ↓
“成功！”
```

## 3. 产品支柱

### 3.1 可理解的物理

物体行为应该尽量符合玩家直觉。除非关卡明确引入特殊规则，否则球应该受重力、碰撞、摩擦和弹性等自然规则影响。

### 3.2 可观察的因果链

玩家应该能看清“哪个物体触发了哪个物体”。因此动画速度、碰撞反馈、声音和暂停/回放能力都属于后续重点。

### 3.3 低门槛摆放

手机操作必须足够简单：拖动、旋转、删除、开始、暂停、重置是基础动作。

### 3.4 高上限关卡

简单关卡教会单个机制；困难关卡组合多个机制，但不依赖不可预测的随机行为。

## 4. 阶段范围

### P0

目标：验证最基本的物理摆放循环。

包含：

- 小球
- 木板
- 斜坡
- 目标区
- 拖动
- 开始/暂停/重置
- Android 构建

不包含：

- 齿轮
- 绳子
- 剪刀
- 气球
- 磁铁
- 炸弹
- 关卡编辑器
- 用户账号
- 联网

### P1

目标：形成真正的机械连锁玩法。

计划加入：弹簧、绳子、剪刀、齿轮、开关、气球、磁铁、炸弹等。

### P2

目标：关卡系统数据化，并提供正式关卡选择、星级评价和进度保存。

### P3

目标：玩家关卡编辑器。

### P4

目标：在线关卡库、分享、排行榜和每日挑战。

## 5. 非目标

当前阶段不做：

- 3D 物理
- PvP
- 实时多人
- 复杂联网同步
- AI 自动解题作为核心玩法
- 直接移植旧游戏代码或素材

## 6. 成功指标

P0 的成功不是下载量，而是以下技术和体验指标：

- 第一关 100% 可解。
- 新用户无需解释即可理解“拖动 → 开始 → 目标”的基本流程。
- Android 真机 60 FPS 运行简单关卡。
- 重置后状态与初始状态一致。
- 同一关卡在相同初始状态下结果稳定。
- 新增一个简单组件不需要修改现有所有组件代码。
