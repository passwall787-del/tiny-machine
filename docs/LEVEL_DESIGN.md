## 难度
1~8 星，每四关左右提升一次复杂度。难度不是单纯增加组件数量，而是逐渐增加路径规划、时序和机关组合。

## 可解性原则
1. 每关必须有且仅有一个 Ball。
2. Goal 必须在编辑边界内。
3. 首轮模板必须提供至少一条默认可运行路径。
4. 机关不能因为测试摆放而无意阻断主路径。
5. 真机发现不可解时，优先修 LevelData 参数，不修改核心规则绕过问题。

## P3 后续冻结流程
模板关卡 → Android 真机测试 → 记录失败原因 → 调整布局/参数 → CI → 再次真机 → 通过后冻结为显式 JSON。
