## 当前首轮模板
所有官方关卡都保留一条稳定的六段坡道默认路径；`pattern` 用于放置待玩家重新排列的机关展示组件。自动化会实际运行默认布局，确保每关先有稳定基线。

## 难度
1~8 星。当前 `slope_count` 保留为关卡元数据，首轮安全模板统一使用六段坡道；后续冻结显式关卡时再让它参与布局变化。

## 可解性原则
1. 每关必须有且仅有一个 Ball。
2. Goal 必须在编辑边界内。
3. 默认布局必须可以实际运行到 SUCCESS。
4. 机关展示位置不能无意阻断默认路径。
5. 真机发现不可解时，优先修改 LevelData 参数，不修改核心规则绕过问题。

## P3 冻结流程
模板关卡 → Android 真机测试 → 记录失败原因 → 调整布局/参数 → CI → 再次真机 → 通过后冻结为显式 JSON。
