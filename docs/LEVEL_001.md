# Level 001 · 基础斜坡

## 状态

**P1 回归关卡**

该关卡保留 P0 的基础物理路线，用于每次修改机关系统后的回归测试。

## 目标

让小球沿三段斜坡和最终木板进入右下角绿色目标区。

## 组件

```text
Slope 1
Slope 2
Slope 3
Board
Ball
Target
```

## 设计意图

这是整个项目的“物理基线”。它不依赖任何 P1 机关。

如果 P1 修改导致 Level 001 无法稳定完成，应先修复物理核心，再继续增加机关。

## 关键要求

- 三段斜坡视觉方向与 CollisionPolygon2D 一致。
- 相邻斜坡之间不能存在不可跨越的高度差。
- 最终木板负责把球导向目标。
- 底部和左右边界防止球直接永久掉出场景。

## P1 新规则回归

球进入 Target 后必须：

1. 立即进入 SUCCESS。
2. 小球停止。
3. 所有动态物体停止。
4. 机关停止。
5. UI 锁定为完成状态。
6. Reset 后完全恢复。

## 验收

```text
[ ] 可以从 EDITING 开始
[ ] 点击开始后球运动
[ ] 球最终进入 Target
[ ] Target 进入事件只触发一次成功
[ ] 成功后球不再继续运动
[ ] Reset 后可再次运行
[ ] Pause / Resume 正常
[ ] Android 触摸可正常拖动组件
```
