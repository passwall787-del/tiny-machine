# Level 001 — 斜坡入门

## 目标

让小球从左上方出发，经过连续斜坡和最后一块木板，进入右下角绿色目标区。

## 当前默认布局

```text
Y ↓

        Ball
         ●

          ╲  Slope 1
           ╲
            ╲
                 ╲  Slope 2
                  ╲
                   ╲
                        ╲  Slope 3
                         ╲
                          ───── Board ────  Target
```

实际坐标由 `main.gd::_build_level()` 定义；本文件记录设计意图，不替代代码中的实际数据。

## 组件

| ID | 类型 | 作用 |
|---|---|---|
| ball-1 | Ball | 玩家要引导的主要物体 |
| slope-1 | Slope | 第一个高度转换 |
| slope-2 | Slope | 第二个高度转换 |
| slope-3 | Slope | 第三个高度转换 |
| board-1 | Board | 最终导向目标 |
| target-1 | Target | 成功判定区域 |

## 设计要求

- 默认布局必须可解。
- 玩家无需旋转组件。
- 玩家无需精确移动默认组件。
- 物理路线应该从左上向右下。
- 目标应该明显可见。

## 验证

每次修改第一关后执行：

1. Reset。
2. 不移动任何组件。
3. Start。
4. 观察小球是否依次接触三段斜坡。
5. 观察小球是否进入最终木板。
6. 确认小球进入 Target。
7. Reset。
8. 连续重复至少 10 次。

## 已知历史问题

### 2026-08-28：不可解

原因：早期版本没有正确验证斜坡的物理方向，导致视觉表面与实际碰撞路线不一致；同时缺少足够的边界保护。

修复：重新调整斜坡方向、路线高度和边界，并把“视觉几何 = 碰撞几何 = 旋转方向”加入物理文档。

## 后续

P1 不应继续把更多复杂机关直接堆进这个关卡。建议保留 Level 001 作为最小物理回归测试关卡，并新建独立关卡验证新机关。
