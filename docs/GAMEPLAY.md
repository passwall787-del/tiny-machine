# 游戏规则

## 核心目标
玩家通过拖动、旋转、组合机械组件，让小球最终进入绿色目标区。

## 编辑阶段
- 组件可以拖动。
- 默认 20px 网格吸附，可关闭。
- 旋转每次 15°。
- 多选模式可以一起移动组件。
- 删除、撤销、重做可用于快速试错。
- 保存/加载使用本机 `user://` 存档。

## 运行阶段
点击“运行”后进入物理模拟；编辑按钮锁定。

### 通关
小球进入目标 Area2D 后，立即：
1. 状态切换为 SUCCESS。
2. 停止组件模拟。
3. 冻结动态物体。
4. 清零速度。
5. 显示成功动画。

不会继续让已经通关的物理世界运行。

### 失败
- 小球掉出场地。
- 单次模拟超过 18 秒。

失败后显示重试入口，不破坏玩家编辑布局。

## 机关
- Spring：一次性冲量。
- Switch：触发后激活弹簧/齿轮。
- Gear：激活后旋转并提供切向冲量。
- Rope：可被 Scissors 逻辑剪断。
- Balloon：持续上浮。
- Magnet：在近距离吸引小球。
- Bomb：接近后产生一次爆炸冲量。

## 教程
1. 连续斜坡。
2. 旋转与网格吸附。
3. 多选。
4. 撤销/重做。
5. 终端通关规则。

## 关卡
P3 首轮提供 32 个官方关卡，难度 1~8 星。当前使用数据驱动模板生成，后续根据真机测试结果逐关冻结和调参。
