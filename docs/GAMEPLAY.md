# 游戏规则

## 核心目标
玩家通过从零件仓库取出机械组件、拖动/旋转并组合它们，让启动后的小球最终进入绿色目标区。

## 关卡初始状态
官方关卡每次开始时施工区为空：

- 小球固定在 START 发射位置，不占用玩家零件库存。
- 目标区固定在关卡目标位置。
- 玩家只能从当前关卡的零件仓库取得有限数量的组件。
- 点击零件卡片会把组件放入施工区并自动选中。
- 玩家负责继续拖动、旋转和组合这些组件。
- 至少放置一个零件后才能点击“发射小球”。

这使每一关都遵循：

```text
空施工区 → 取零件 → 摆放/旋转 → 检查 → 发射小球 → 观察连锁反应
```

## 编辑阶段
- 组件可以拖动。
- 默认 20px 网格吸附，可关闭。
- 旋转每次 15°。
- 多选模式可以一起移动组件。
- 删除会把组件数量返还到零件仓库。
- 撤销、重做用于快速试错。
- 保存/加载使用本机 `user://` 存档。
- 零件仓库实时显示剩余数量。
- 小球不可被编辑器拖动。

## 运行阶段
点击“发射小球”后进入物理模拟；编辑按钮和零件仓库锁定。

### 通关
小球进入目标 Area2D 后，立即：

1. 状态切换为 SUCCESS。
2. 停止组件模拟。
3. 冻结动态物体。
4. 清零速度。
5. 显示成功动画。

同时使用“上一帧 → 当前帧”的轨迹检测，避免高速小球跨过目标区域时漏判。

不会继续让已经通关的物理世界运行。

### 失败
- 小球掉出施工区。
- 单次模拟超过 18 秒。

失败后显示重新施工入口；重新施工会清空当前布局，回到本关的空施工状态。

## 机关
- Spring：一次性冲量。
- Switch：触发后激活弹簧/齿轮。
- Gear：激活后旋转并提供切向冲量。
- Rope：可被 Scissors 逻辑剪断。
- Balloon：持续上浮。
- Magnet：在近距离吸引小球。
- Bomb：接近后产生一次爆炸冲量。

## 零件库存
库存属于关卡数据 `LevelData.inventory`，不是全局无限资源。这样可以控制关卡难度并允许后续加入诱饵零件。

## 教程
1. 从空场地开始搭建第一条斜坡路线。
2. 练习旋转与网格吸附。
3. 练习多选。
4. 练习撤销/重做。
5. 理解目标进入后的终端通关规则。

## 关卡
P3 首轮提供 32 个官方关卡，难度 1~8 星。当前每个官方关卡都保存独立的自动化解法布局，但玩家实际进入关卡时不会看到这些零件。
