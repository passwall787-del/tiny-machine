# Release Checklist

## 功能

- [ ] 所有计划功能已完成。
- [ ] 关键关卡全部可解。
- [ ] 成功/失败状态正确。
- [ ] Reset 无残留状态。

## UI

- [ ] 主按钮清晰可见。
- [ ] 触摸区域足够大。
- [ ] 文本无截断。
- [ ] 横屏安全区正常。
- [ ] 不同屏幕比例没有关键 UI 遮挡。

## 物理

- [ ] 默认解连续成功。
- [ ] 无明显穿透。
- [ ] 无明显卡死。
- [ ] 长时间运行稳定。
- [ ] 不依赖设备帧率。

## Android

- [ ] ARM64 安装测试。
- [ ] 启动测试。
- [ ] 返回/切后台测试。
- [ ] 屏幕旋转策略确认。
- [ ] 音频焦点策略确认（若有音频）。
- [ ] 重新安装测试。
- [ ] 升级安装测试。

## Build

- [ ] GitHub Actions 成功。
- [ ] APK 文件存在。
- [ ] APK 大小合理。
- [ ] SHA-256 已记录。
- [ ] version name 正确。
- [ ] version code 正确。

## Release signing

正式版：

- [ ] 使用正式 keystore。
- [ ] keystore 不在仓库。
- [ ] 密码来自 GitHub Secrets/安全存储。
- [ ] Debug signing 已关闭。
- [ ] AAB 构建成功。

## 文档

- [ ] README 更新。
- [ ] CHANGELOG 更新。
- [ ] 路线图更新。
- [ ] 已知问题更新。
- [ ] 新增组件文档完成。
